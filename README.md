3 different versions i.e. K estimation with priors, K estimation without priors and estimation are provided.  
Run the training script "train.sh" Uncomment the appropriate estimation block in "1" and the loss file in "2"  
Set the training options in train_options.py. You can use latent, identity losses.  
Select the appropriate model in "3"  
Run the training using "sh train.sh"  
The code is adapted from the combogan training provided in "https://github.com/AAnoosheh/ToDayGAN/"
